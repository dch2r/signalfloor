# Security policy

## Reporting a problem

If you find a security problem in signalfloor, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/dch2r/signalfloor/security/advisories/new).
Do not open a public issue.

Include what you found, how to reproduce it and which version you used. You will get a reply
within a week.

## Supported versions

Only the latest release gets fixes while the project is below version 1.0.
